## Practical Database Project

### Online Shopping Database

As part of the final learning stage, I designed an Online Shopping Database to understand how SQL concepts work together in a real-world scenario.

**Main database tables:**

| Table | Description |
|---|---|
| `customers` | Stores customer information |
| `products` | Stores product details and stock |
| `orders` | Stores customer order information |
| `order_items` | Stores products and quantities in each order |
| `payments` | Stores payment information |

**Concepts applied:**

- Primary Keys and Foreign Keys
- NOT NULL, UNIQUE, CHECK and DEFAULT constraints
- INSERT, UPDATE and DELETE operations
- Multi-table JOIN queries
- GROUP BY and HAVING
- Subqueries and correlated queries
- Views for reporting
- Transactions using COMMIT and ROLLBACK
