## 1. INSERT with Identity (`AUTO_INCREMENT`)

### Introduction

In MySQL, `AUTO_INCREMENT` automatically generates a numeric value when a new row is inserted. It is commonly used for primary key columns such as student IDs, employee IDs, and order IDs.

### Example: Creating a Table

```sql
CREATE TABLE students (
    student_id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50),
    age INT,
    department VARCHAR(30)
);
```

Here:
- `student_id` is the unique identifier for each student.
- `AUTO_INCREMENT` generates the ID automatically.
- `PRIMARY KEY` uniquely identifies each record.

### Inserting Records

```sql
INSERT INTO students (name, age, department)
VALUES ('Rahul', 20, 'CSE');

INSERT INTO students (name, age, department)
VALUES ('Priya', 21, 'ECE');

INSERT INTO students (name, age, department)
VALUES ('Arjun', 22, 'IT');
```

Notice that we do not provide `student_id`. MySQL generates it automatically.

### Viewing the Records

```sql
SELECT * FROM students;
```

Example output:

| student_id | name | age | department |
|---:|---|---:|---|
| 1 | Rahul | 20 | CSE |
| 2 | Priya | 21 | ECE |
| 3 | Arjun | 22 | IT |

*Note: The actual generated IDs can differ depending on previous inserts and table configuration.*

### Important Points

- `AUTO_INCREMENT` is commonly used with an integer primary key.
- You usually omit the auto-increment column when inserting a new row.
- Generated IDs are not guaranteed to be gap-free.
- A table can have only one `AUTO_INCREMENT` column.

## 2. INSERT: Creating a Table from Another Table

### Introduction

In MySQL, you can create a new table from an existing table using `CREATE TABLE ... AS SELECT`.

This copies the selected data into a new table and derives its columns from the query result.

### Syntax

```sql
CREATE TABLE new_table AS
SELECT column1, column2
FROM existing_table;
```

### Example

Assume the `students` table contains student information.

Create a new table containing only student names and departments:

```sql
CREATE TABLE student_departments AS
SELECT name, department
FROM students;
```

View the new table:

```sql
SELECT * FROM student_departments;
```

Example output:

| name | department |
|---|---|
| Rahul | CSE |
| Priya | ECE |
| Arjun | IT |

### Creating a Table Without Copying Rows

To create a table with the selected columns but no data:

```sql
CREATE TABLE student_template AS
SELECT name, department
FROM students
WHERE 1 = 0;
```

The condition `WHERE 1 = 0` is always false, so no rows are copied.

### Important Points

- `CREATE TABLE ... AS SELECT` creates a new table.
- It copies the query's result rows when the query returns rows.
- It does not automatically copy all original table constraints, indexes, or `AUTO_INCREMENT` properties.
- The source table remains unchanged.

## 3. INSERT: Rows from One Table to Another

### Introduction

The `INSERT INTO ... SELECT` statement copies rows from an existing table into another table.

Unlike `CREATE TABLE ... AS SELECT`, it inserts data into a table that already exists.

### Syntax

```sql
INSERT INTO destination_table (column1, column2)
SELECT column1, column2
FROM source_table
WHERE condition;
```

### Example: Creating the Tables

```sql
CREATE TABLE current_students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50),
    department VARCHAR(30)
);

CREATE TABLE cse_students (
    student_id INT PRIMARY KEY,
    name VARCHAR(50),
    department VARCHAR(30)
);
```

Insert some records into the source table:

```sql
INSERT INTO current_students
    (student_id, name, department)
VALUES
    (101, 'Rahul', 'CSE'),
    (102, 'Priya', 'ECE'),
    (103, 'Arjun', 'CSE');
```

Copy only CSE students to the destination table:

```sql
INSERT INTO cse_students
    (student_id, name, department)
SELECT student_id, name, department
FROM current_students
WHERE department = 'CSE';
```

View the destination table:

```sql
SELECT * FROM cse_students;
```

Example output:

| student_id | name | department |
|---:|---|---|
| 101 | Rahul | CSE |
| 103 | Arjun | CSE |

### Important Points

- The destination table must already exist.
- The selected columns must match the destination columns in number and compatible data types.
- `WHERE` filters which rows are copied.
- Primary key conflicts can cause an insertion error.
- The source table is not modified by this statement.

### Difference Between the Two Statements

| Statement | Purpose |
|---|---|
| `CREATE TABLE ... AS SELECT` | Creates a new table and copies query results |
| `INSERT INTO ... SELECT` | Inserts query results into an existing table |

## 4. UPDATE with Computed Columns

### Introduction

An UPDATE statement can calculate a new value using existing column values, numbers, or mathematical expressions.

This is useful for calculating salary increases, updated prices, marks, discounts, and totals.

### Example: Employee Table

```sql
CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    employee_name VARCHAR(50),
    salary DECIMAL(10, 2)
);
```

Insert sample records:

```sql
INSERT INTO employees
    (employee_id, employee_name, salary)
VALUES
    (1, 'Rahul', 30000.00),
    (2, 'Priya', 40000.00),
    (3, 'Arjun', 50000.00);
```

### Example 1: Increase Salary by 10%

```sql
UPDATE employees
SET salary = salary * 1.10
WHERE employee_id = 1;
```

If Rahul's salary was ₹30,000, it becomes ₹33,000.

The expression `salary * 1.10` calculates the original salary plus 10%.

### Example 2: Increase Every Employee's Salary by ₹2,000

```sql
UPDATE employees
SET salary = salary + 2000;
```

This updates every row because there is no `WHERE` clause.

### Example 3: Calculate a Discounted Price

Suppose a `products` table contains a `price` column.

```sql
UPDATE products
SET price = price * 0.90
WHERE price > 1000;
```

This reduces the price of products costing more than 1,000 by 10%.

### Example 4: Update Using Multiple Columns

```sql
UPDATE student_marks
SET total = subject1 + subject2 + subject3
WHERE student_id = 101;
```

This example assumes `student_marks` contains the columns `total`, `subject1`, `subject2`, `subject3`, and `student_id`.

### Important Note About Computed Columns

A regular column whose value is calculated using UPDATE is stored like other data and may become outdated if its source values change.

MySQL also supports generated columns, whose values are derived from expressions automatically. A generated column is defined in the table schema and is not updated directly with an ordinary UPDATE assignment.

## Quick Revision

| Concept | Purpose |
|---|---|
| `AUTO_INCREMENT` | Generates numeric IDs automatically |
| `CREATE TABLE ... AS SELECT` | Creates a table from query results |
| `INSERT INTO ... SELECT` | Copies rows into an existing table |
| `UPDATE ... SET column = expression` | Calculates and updates column values |
| `WHERE` | Restricts which rows are affected |
